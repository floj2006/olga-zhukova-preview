# Ольга Жукова · Gold Premium

Готовый адаптивный статический сайт. Публикуемая папка — `dist` (сохранена существующая конфигурация `.openai/hosting.json`). Сборка не требуется.

## Запуск

`npm start` → http://127.0.0.1:4173. Для другого порта задайте переменную окружения `PORT`.

## Настройка стоимости

Все тарифы находятся в `dist/pricing.js`. Сейчас `demo: true`: суммы демонстрационные, на сайте это явно указано. Перед публикацией подтвердите и замените базовые тарифы и доплаты, затем установите `demo: false`. Итог — сумма выбранных параметров. Если длительность не определена, учитывается до 4 часов; выезд в другой город и неопределённое музыкальное сопровождение уточняются отдельно.

Калькулятор содержит 5 шагов, сохраняет выбор в sessionStorage, разрешает менять ответы, показывает итог с расшифровкой. Кнопка точного расчёта открывает контакты и позволяет скопировать параметры. Серверной отправки заявок нет; приложение не имитирует её. Телефон: +7 911 444-90-71.

## Файлы

- `dist/index.html` — содержание страницы.
- `dist/styles.css` — палитра, композиция, адаптивность и анимация.
- `dist/app.js` — калькулятор, меню, окно связи и копирование.
- `dist/pricing.js` — стоимость услуг.
- `dist/olga.jpg` — исходная фотография Ольги из проекта.
- `dist/images/` — локальные атмосферные фотографии Unsplash; это иллюстрации форматов, а не портфолио проведённых Ольгой мероприятий.
- `dist/fonts/` и `dist/fonts.css` — локальные Cormorant Garamond и Manrope с лицензиями OFL. Внешние запросы для работы сайта не нужны. Обновить файлы шрифтов из установленных пакетов можно командой `node scripts/prepare-fonts.mjs`.

Источники иллюстраций (идентификаторы Unsplash): `photo-1519167758481-83f550bb49b3`, `photo-1519741497674-611481863552`, `photo-1519671482749-fd09be7ccebf`, `photo-1519225421980-715cb0215aed`, `photo-1511795409834-ef04bbd61622`. Все изображения сохранены локально. Генерация изображения была недоступна; сгенерированные изображения не используются.

## Проверка

`npm install`, `npx playwright install chromium`, затем `npm test` при работающем локальном сервере. Проверки охватывают расчёт, изменение ответов, сохранение выбора, доступность диалога, копирование и его запасной вариант, мобильное меню, управление с клавиатуры, адаптивность на ширинах 320–1920 px и загрузку ресурсов. Автоматическая проверка axe-core по правилам WCAG A/AA выполняется для настольной и мобильной версии. Скриншоты сохраняются в `artifacts/`.

При отключённом JavaScript содержание и контакты остаются доступны; вместо расчёта можно связаться с Ольгой по телефону. Учитывается системная настройка уменьшения анимации.
