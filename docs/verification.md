# Проверка текущей реализации

Дата: 30 сентября 2026. Проверена локальная рабочая копия, не опубликованный Vercel deployment.

## Выполнено

- `npm run test:cloud-check`: проверка отсутствующей конфигурации, запросов только на чтение и отсутствия секретов в сообщениях об ошибках. Это тесты скрипта на подставных ответах, не проверка настоящего Supabase.

- `npm run test:backend`: 22 проверки. Расчёт, занятые/прошедшие даты, повторные заявки, авторизация, CSRF, конфликты версий, публикация фотографий, поиск по всей базе и пагинация.
- `npm test`: выбор услуг, изменение количества, заявка, изменение цены в админке, сохранение черновиков при поиске, восстановление каталога после ошибки сети.
- `npm run test:experience`: календарь в независимых сессиях, личные заметки, фильтры дат, галерея и её публикация, ошибки изображений, клавиатура, свайп, доступность и отсутствие горизонтального переполнения.
- `npm run test:loading`: медленная/недоступная сеть, возврат фокуса, reduced motion, работа без JavaScript, тайм-аут и повтор заявки, навигация, финальная кнопка заявки.
- `npm run test:seo`: 3 проверки генерации метаданных, смены домена, preview-индексации и повторной сборки.
- `npm run build`: генерация SEO, синтаксис JS, JSON и ссылки на статические ресурсы.

Тесты создают отдельные базы и синтетические заявки. Рабочая `.data` не используется для тестовых записей.

## Дополнительные измерения

- Портрет в Hero: 28 КБ при 390 px / DPR 1; 55 КБ при 390 px / DPR 2 и 1440 px / DPR 1; 88 КБ при 1440 px / DPR 2. Исходник — 276 КБ. В каждом сценарии загружался один вариант портрета, без дублирующего preload.
- После удаления 55 правил старого калькулятора полностраничные PNG совпали побайтно на 320, 390, 768 и 1440 px. Это проверка конкретной очистки CSS, не универсальная гарантия отсутствия визуальных ошибок.
- `.env.local`, `artifacts/admin-access.txt` и `.data/state.json` игнорируются Git и не отслеживаются. Содержимое секретов в отчёт не включено.

## Границы проверки и публикация

- Повторная проверка выполнена на Node 24.21.0 из npm-кэша: сборка, 22 backend-теста, 3 SEO-теста и все три браузерных набора прошли. Глобальная установка Node 20.18.0 не изменена. Запуск удалённого CI отдельно не подтверждался.
- В `server/schema.sql` подготовлены атомарная проверка даты и `olga_search_leads`. Пользователь подтвердил, что проекта Supabase пока нет; URL, API-ключ и SQL-подключение не настроены. Облачная проверка заблокирована созданием проекта и предоставлением подключения. Инструкция: [supabase-setup.md](supabase-setup.md).
- Обновления не отправлялись в GitHub и не разворачивались на Vercel в этих этапах. Локальный результат не подтверждает состояние публичного сайта.
- Браузерные проверки не включают Safari/iOS и Firefox. Измерения трафика выполнены локально, полевые Core Web Vitals не измерялись.
- Уведомления о заявках во внешние сервисы не подключены: канал и получатель не заданы. Заявки сохраняются и доступны в админке.
- Улучшения реализованы поэтапно; этот отчёт не означает выполнения всех дополнительных предложений первоначального аудита. В частности, проверка загрузок изображений на сервере пока основана на сигнатуре и размере, без полноценного декодирования.
