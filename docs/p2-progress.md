# P2 — дополнительные улучшения

Начато 30 сентября 2026 по текущей реализации. В репозитории нет сохранённой подробной матрицы P2; первый этап выбран из раздела Admin UX исходного задания.

## Первый этап: управление большой галереей

- Поиск по описанию и подписи, включая несохранённые правки.
- Фильтры «Все фотографии», «На сайте», «Скрыто с сайта» по сохранённому статусу публикации.
- Счётчик результатов и пустое состояние.
- Фильтрация сохраняет введённые данные и не делает запросов к API.
- Перестановка снимков доступна при сброшенных фильтрах: порядок всегда относится ко всей галерее.
- Новых зависимостей, изменений схемы и публичного дизайна нет.

Проверки: `npm run build`, `npm run test:experience`. Браузерный сценарий проверяет фильтрацию, поиск без учёта регистра, сохранение черновика при смене запроса и блокировку перестановки отфильтрованных фотографий.

Облачная проверка Supabase остаётся отдельным незакрытым пунктом; начало P2 не означает её завершения.

## Второй этап: расчёт для клиента

- В раскрытой заявке добавлена кнопка «Скопировать расчёт».
- Текст содержит услуги, количество, сохранённые цены и предварительный итог. Изменение каталога не меняет старый расчёт.
- Телефон, имя, комментарий клиента и внутренние заметки в текст не включаются. Отправка во внешние сервисы не выполняется.
- При запрете Clipboard API открывается подписанное поле с выделенным текстом для ручного копирования.
- Для заявки без услуг не показывается вводящий в заблуждение нулевой итог.

Проверки: сборка, `test:backend` (формат сохранённого расчёта и отсутствие приватных полей), `npm test` (отказ копирования, ручной вариант, успешное повторное копирование).

## Третий этап: быстрый переход по календарю

- Выбор месяца и года без последовательного перелистывания; диапазон 2000–2099 совпадает с существующей навигацией.
- Кнопка возврата к текущему месяцу. Текущий месяц определяется по часовому поясу мероприятий, как и проверка даты заявки.
- Переключение месяца не меняет занятость дат, выбранные даты и черновики заметок.
- Поле синхронизируется со стрелками и действием «Показать в календаре», блокируется во время сохранения.
- При отсутствии поддержки month-input можно ввести ГГГГ-ММ; неверный месяц отклоняется.

Проверка: `test:experience` — переход к далёкому месяцу, возврат к текущему, синхронизация со стрелками и сохранение несохранённой заметки; также существующие проверки мобильной вёрстки и доступности.

## Четвёртый этап: недоступные фотографии в админке

- Вместо сломанного изображения показывается сообщение с кнопкой повторной загрузки.
- Повтор загружает только изображение; введённые подписи и настройки не сбрасываются.
- При некорректном адресе повтор недоступен, но редактирование и удаление записи сохраняются.
- Успешная загрузка возвращает фотографию на место без перезагрузки страницы.

Проверки: сборка и `test:experience` — повреждённый ответ изображения, доступность сообщения, повтор после восстановления сети, сохранение черновика подписи и отсутствие переполнения на ширине 320 px.

## Пятый этап: выбор файла перед загрузкой

- Выбранный файл можно убрать отдельно от описания, подписи и настроек публикации.
- Предпросмотр и его временный URL очищаются; фокус возвращается к выбору файла.
- Во время отправки кнопка недоступна вместе с остальными полями формы.
- Сообщение об успешной загрузке учитывает фактический статус публикации: скрытое фото не называется опубликованным.

Проверки: сборка и `test:experience` — очистка файла, сохранение текстов, повторный выбор, загрузка скрытого фото и последующая публикация.

## Шестой этап: повреждённые исходные изображения

- Предпросмотр проверяет декодирование выбранного файла в браузере, а не только его расширение и MIME.
- Повреждённый файл убирается из выбора с понятным сообщением; подпись и описание сохраняются.
- Результат декодирования старого файла игнорируется после смены или очистки выбора.
- Проверка при отправке и серверная валидация остаются на месте; браузерная проверка не заменяет серверное декодирование изображений.

Проверки: сборка и `test:experience` — файл с MIME image/png и некорректным содержимым, очистка предпросмотра, сохранение полей и последующая успешная загрузка фотографии.

## Седьмой этап: отмена правок отдельной заявки

- «Отменить правки» восстанавливает статус и внутреннюю заметку последней загруженной или сохранённой версии одной заявки.
- Остальные черновики не затрагиваются; запрос на сервер не отправляется.
- Кнопка недоступна без изменений и во время сохранения. После отмены фокус возвращается к статусу заявки.
- Действия переносятся на следующую строку при недостатке места.

Проверки: сборка и `npm test` — сохранение заявки, изменение статуса и заметки, восстановление сохранённых значений и состояния кнопок.

## Восьмой этап: клавиатура календаря

- Сегодняшний день подчёркнут и помечен `aria-current="date"`; озвучиваемое название содержит «сегодня».
- Стрелки перемещают фокус на день или неделю с переходом между месяцами.
- Page Up / Page Down меняют месяц с корректировкой дня до последнего существующего; Home / End ведут к началу и концу месяца.
- Границы 2000–2099 сохраняются. Навигация не записывает занятость и не меняет выделение дат.
- Добавлена видимая подсказка управления, палитра сохранена.

Проверки: сборка и `test:experience` — отметка сегодня, переход 31 января → 29 февраля високосного года, переход через границу месяца в обе стороны, Home / End и отсутствие изменений занятости.
